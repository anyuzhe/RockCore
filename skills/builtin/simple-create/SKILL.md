# Simple Create

1. Inspect the project entry point and one nearby example at most.
2. Create the smallest complete implementation in the requested location.
3. Write files early; do not spend repeated turns rediscovering structure.
4. Use local assets and existing conventions.
5. Run one focused syntax, build, or smoke check and finish.
