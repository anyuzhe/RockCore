# Simple Edit

1. Locate the exact target with search and read only its immediate context.
2. Preserve unrelated user changes and the existing encoding and line endings.
3. Apply a focused patch within four exploratory reads.
4. Verify the changed region and one relevant deterministic check.
5. Stop when the requested state is present; do not rewrite for appearance.
